Is this image AI-generated?

Upload a picture and VisionGuard estimates whether a generative model or a human made it. The image is analysed in memory and never stored.

Before you trust the verdict

  • The model was trained on about 1,000 web images (art, portraits, animals, landscapes). New generators, heavy editing, screenshots or compression can fool it.
  • "Real" means made by people: photos and human paintings or illustrations.
  • Treat the result as a hint, not proof. Never accuse someone of faking an image based on this tool alone.
